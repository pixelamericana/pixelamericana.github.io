Set it

  1. Mac: System Settings › Wallpaper › Add Photo, or right-click the downloaded file in Finder › Set Desktop Picture.
  2. Windows: right-click the file › Set as desktop background. Choose Fill under Settings › Personalization › Background.
  3. Linux (GNOME): right-click the file in Files › Set as Wallpaper.
