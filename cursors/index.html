Install

  1. Windows: unzip, right-click install.inf › Install, then Settings › Mouse › Additional mouse settings › Pointers › pick the scheme › Apply.
  2. macOS: macOS has no built-in cursor setting, so install the free Mousecape app (on macOS 15 or newer, use the maintained version linked in the zip), double-click the .cape file and click Apply.
  3. Linux: copy the theme folder into ~/.icons, then pick it in your desktop's cursor settings.

Mousecape uses private macOS interfaces, so a macOS update can break it until the app is updated. It never changes system files and you can switch back to Default any time.
