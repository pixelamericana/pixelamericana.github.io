Download for VS Code

One file, all three themes. In VS Code, open Extensions, click the … menu, choose Install from VSIX… and pick the file. Then run Preferences: Color Theme and choose a Pixel Americana theme.

Install in Chrome

About a minute, start to finish

  1. Download the New Tab extension or a set's Chrome theme, unzip it and move the folder somewhere it can stay (not Downloads).
  2. Go to chrome://extensions and switch on Developer mode, top right.
  3. Click Load unpacked and choose the folder.
  4. Open a new tab. The extension and a theme can run together. To undo a theme, use chrome://settings/appearance › Reset.

Works in Chrome, Edge, Brave, Opera and Vivaldi. Chrome keeps one theme at a time, so loading another replaces it. If Chrome asks whether to keep the new tab change, choose Keep it. One-click installs from the Chrome Web Store are coming.
