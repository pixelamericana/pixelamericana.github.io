On the record player

Install

About a minute, start to finish

  1. Download the New Tab or a set's browser theme. Unzip it and move the folder somewhere it can stay (not Downloads).
  2. Go to chrome://extensions (edge://extensions in Edge) and switch on Developer mode.
  3. Click Load unpacked and choose the folder.
  4. Open a new tab. If the browser asks whether to keep the change, choose Keep it. The New Tab and a theme can run together.

The browser keeps one theme at a time, so loading another replaces it. To undo a theme: chrome://settings/appearance › Reset. One-click installs from the Chrome Web Store are coming.

  1. Download the Firefox version of the New Tab or a theme.
  2. Go to about:debugging › This Firefox › Load Temporary Add-on.
  3. Pick the zip (or manifest.json inside it). It stays until Firefox restarts.

Firefox only installs add-ons permanently once Mozilla has signed them. Signed one-click versions are on the way; they'll replace these files here.

  1. Safari has no browser themes, but the New Tab works as a web page.
  2. Safari › Settings › General: set New windows open with and New tabs open with to Homepage.
  3. Set the homepage to https://pixelamericana.github.io/newtab/. Wallpapers and stickers work on any Mac or iPhone.
