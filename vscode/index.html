VS Code themes

For your code editor

Old Glory, Haze Gray, Lookout, Parchment as color themes for Visual Studio Code, Cursor and VSCodium. Every code color has at least 4.5:1 contrast with the background, comments at least 3:1, and the built-in terminal uses the matching terminal theme.

  • Old Glory Dark
  • Haze Gray Dark / neutral
  • Lookout Night
  • Parchment Light
Download for VS Codevsix, all themes

Install

  1. Download the .vsix file.
  2. In VS Code, open the Extensions view, click the … menu › Install from VSIX… and pick the file.
  3. Run Preferences: Color Theme (Cmd/Ctrl+K then Cmd/Ctrl+T) and choose a Pixel Americana theme.
