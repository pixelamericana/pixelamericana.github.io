Install

  1. macOS Terminal: double-click the .terminal file, then Terminal › Settings › Profiles, select it and click Default.
  2. iTerm2: double-click the .itermcolors file, then Settings › Profiles › Colors › Color Presets.
  3. Ghostty / kitty / Alacritty: copy the file into your config folder and point your config at it. The README in the zip has the one line to add.
  4. Windows Terminal: Settings › Open JSON file, paste the scheme into "schemes", then pick it under your profile's Appearance.
