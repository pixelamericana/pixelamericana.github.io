Install

  1. Download a theme and unzip it. Move the folder somewhere permanent.
  2. Go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the theme's folder. The browser recolors right away.
  4. To undo: chrome://settings/appearance › Reset to default.

Works in Chrome, Edge, Brave, Opera, Vivaldi and Arc. Firefox: about:debugging › This Firefox › Load Temporary Add-on › pick the zip (lasts until Firefox restarts until the signed versions are up). One-click installs from the Chrome Web Store are planned.
